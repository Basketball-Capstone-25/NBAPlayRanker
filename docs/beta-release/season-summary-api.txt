Season summary API - SCRUM-495 / SCRUM-772

This first section adds GET /analytics/playtypes/summary. It accepts season,
our, opp, k and w_off. The only supported period is "season". Coaches and
analysts can use it; the existing detailed uplift exports remain analyst-only.

The calculation reuses the existing Top-K rankings and uplift calculation:
- Observed PPP = all recorded team-season offensive points / possessions.
- Modeled PPP = sum(predicted PPP * play possessions) / selected possessions.
- Modeled uplift = modeled PPP - observed PPP.
- Play usage = play possessions / all team-season offensive possessions * 100.

For example, if Cut has 100 of the team's 400 possessions, its usage is 25%.
It stays 25% even if Cut is the only selected play. Shortlist weights used in
the modeled PPP calculation are a different denominator.

Missing seasons or unmatched play types return status=no_data, summary=null
and an empty play_types list. Invalid filters return 400/422. Bad source data
returns 503 rather than an invented zero. The response includes its filters,
source version and limitations. These are historical comparisons, not proof
that following the recommendations will improve scoring.

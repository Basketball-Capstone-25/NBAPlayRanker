# Alpha release model

The two implemented Alpha use cases are Compare Usage and Efficiency (SCRUM-695) and View Opponent Defensive Weak Spots (SCRUM-696). Each has a functional overview, a collaboration realization, a structural design and a detailed sequence. Both link to the Baseline Comparisons native wireflow, which has eight screen states.

The four Beta/Final use cases are planned requirements. Their presence in the model does not mean those features are implemented.

Start with Functional Overview - Baseline Comparisons.png, then the two Collaboration Overview images, Structural Design images and Detailed Sequence images. Wireflow - Baseline Comparisons.png shows navigation and state transitions; ALPHA-1 through ALPHA-8 show the native conceptual screen designs. Actual app screenshots are separate test evidence.
